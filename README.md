# 🚀 AI Mentor (DevMind)

AI-powered Offline Code Review System built using Spring Boot, React, and Local LLM Integration.

---

## 🔥 Overview

AI Mentor is a full-stack application that allows developers and students to analyze, review, and improve code **without internet dependency** using a locally integrated AI model.

---

## ⚡ Features

* AI-based Code Review (Bug detection, improvements, optimization)
* Real-time Code Explanation
* Code Optimization Suggestions
* History Tracking of code reviews
* Secure REST API integration
* Offline AI processing (No external API dependency)

---

## 🧠 How It Works

1. User writes or pastes code in frontend editor
2. Code is sent to Spring Boot backend via REST API
3. Backend processes input using local AI model (LLM)
4. AI generates:

   * Bug detection
   * Suggestions
   * Explanation
5. Response is sent back and displayed in UI

---

## 🛠️ Tech Stack

**Backend:** Spring Boot, Spring AI
**Frontend:** React.js (Monaco Editor)
**Database:** MySQL
**AI Integration:** Local LLM (Offline Inference)
**API:** REST

---

## ▶️ How to Run

### Backend

```
mvn spring-boot:run
```

### Frontend

```
cd ai-mentor-ui
npm install
npm start
```
