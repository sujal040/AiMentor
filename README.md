# AI Mentor 🚀

AI-powered Code Reviewer built using Spring Boot + React.

## 🔥 Features
- Code Review (bugs, improvements, complexity)
- Code Explanation
- Code Optimization
- History tracking
- Secure API access

## 🛠 Tech Stack
- Backend: Spring Boot, Spring AI
- Frontend: React (Monaco Editor)
- Database: MySQL
- API: REST

## How to Run

### Backend
```bash
mvn spring-boot:run
```
### Frontend
```bash
cd ai-mentor-ui
npm install
npm start
```
🌐 URLs
Frontend:``` http://localhost:3000  ```
Backend: ``` http://localhost:8080  ```
